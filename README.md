# 实译 / Real-time Interpreter

面向英文场景的实时中文字幕工具，使用 Electron + Vue 3 + TypeScript。当前提供 **macOS 本地麦克风试用链路** 和可切换的模拟演示。识别、翻译和记录均在本机处理；模型与运行工具准备好后，使用时不需要外网。

真人试用已发现重复识别、延迟和自动暂停问题；当前修复了部分故障处理，但真人质量、长时间运行和签名安装包仍未通过验收，不作为正式发布版。

## 在这台电脑体验

项目目录：`/Users/zrr/Desktop/实译`。本机模型和运行工具已准备，生产资源已构建：

```sh
npm start
```

桌面版默认选择“本地麦克风”：

1. 点击“开始翻译”，等待模型准备，首次使用允许麦克风权限。
2. 对着麦克风说英文，页面逐步显示双语字幕；停顿后确认当前片段。
3. “暂停”释放麦克风并冻结字幕，“继续翻译”只接收之后的新声音。
4. “结束”立即停止更新并保存当前双语记录；尚未确认的字幕保留未确认标记。
5. 结束后可切换为“字幕演示”，仍可体验原来的固定模拟数据。

本地记录保存到系统桌面“实译历史记录”文件夹，每轮一个 Markdown 文件。清空或重新开始不会删除历史；关闭窗口前先结束并确认保存成功。音频只在内存中流转，不保存录音。本地与模拟记录分别标注来源。

浏览器 `http://127.0.0.1:5187/` 仍为模拟演示，浏览器结束后提供下载，不能直接使用 Electron 本地模型接口。

开发运行：

```sh
npm run dev:desktop
# 或只启动浏览器模拟预览
npm run dev
```

## 本地准备与架构

- 要求 macOS、Apple Command Line Tools、Node.js 22.12+、Python 3 与 CMake。本次验证 Apple M3 / 24GB、Node.js 22.22.2、CMake 3.31.6。
- 首次依赖安装 `npm ci`，Electron 与模型下载需要网络。已有模型的使用过程完全本地；尚未提供离线安装包。
- 音频：Web Audio / AudioWorklet → 单声道 16kHz → 音量与停顿分段 → Silero VAD → Whisper small 多语言 → Qwen3 4B → 字幕。
- 当前增量识别采用累计短窗口，约每 1.5 秒提交一次，普通片段停顿约 600ms 后确认，累计有声不足 1 秒时等待约 1.2 秒以连接短引导词，最长片段 12 秒；达到 10 秒后优先利用约 280ms 的短停顿结束，减少切入下一句话。不是原生逐词流式识别；首个有效中文延迟仍需真人实测。
- 翻译边界：明确的独立英文疑问句补齐问号；临时结果已有完整句子时先翻译完整部分；尾随残句或明显未完词尾等待后续内容。达到 12 秒硬上限且未完的句子保留 Partial，只与紧接的下一窗口衔接，最多两段；后续内容更新同一字幕行，不改写已确认字幕。等待续句不计作翻译失败；暂停、结束及新会话清除衔接状态。该规则不是通用语义断句，仍需真人核验。
- 原文通过受限通知提前显示，不等待译文完成；已有双语对照不会因下一次临时识别被清空。中文完成后更新同一字幕块，最终确认仍要求原文和译文都完成。
- 队列优先 Final；已有 Final 等待时不追加临时任务，提交 Final 时移除待处理的 Partial；Final 超过限量仍暂停并明确提示可能遗漏，不静默丢弃。完整片段到达时取消同段尚在运行的临时推理，不取消整个会话。相同片段原文不变时复用译文；暂停、结束、清空和新一轮均隔离旧结果。
- Electron 主进程通过受限 IPC 接收限长音频；模型仅监听本机地址，推理子进程使用 `offline.sb` 禁止外网访问，界面禁止外部资源请求。
- 模型加载可取消；暂停与结束后模型保留在内存以便继续，关闭窗口释放模型进程。缺少模型、权限被拒绝、设备断开和处理失败都有提示。
- 对异常连续重复和与音频长度明显不符的识别结果进行保守拦截，不继续翻译、不伪造 Final；页面与历史记录保留未确认状态和原因。正常文字不自动改写。
- 单段翻译或质量检查失败继续监听；连续三个最终片段失败才自动暂停。同一片段的多次 Partial 不重复计数。设备断开、服务请求失败或真实积压仍立即暂停，原因持续显示在顶部。
- 不使用云端 API、登录、数据库、云同步或会议能力。

重新准备模型与运行工具：

```sh
sh scripts/local/build_runtime.sh
python3 scripts/local/fetch_models.py
npm run build
```

构建脚本默认使用 `work/local-runtime/venv/bin/cmake`，或指定 `CMAKE_BIN=/绝对路径/cmake`。源码固定提交，不覆盖已有工具源码改动。模型位于 `models/`，包括多语言 Whisper small、社区量化 Qwen3-4B-Instruct-2507 Q4_K_M、Silero v5.1.2；下载脚本固定版本和 SHA-256。首次下载受中国大陆实际网络可达性影响，可断点重试。

## 检查与复测

| 命令 | 用途 |
|---|---|
| `npm test` | 状态、历史、音频分段、队列、生命周期、权限及原生适配层回归 |
| `npm run typecheck` | Vue、TypeScript、Electron 类型检查 |
| `npm run test:e2e` | 浏览器模拟操作回归 |
| `npm run test:electron` | 已构建桌面版的模拟流程、剪贴板与历史保存 |
| `npm run build` | 类型检查和前端、Electron 构建 |
| `npm run test:local` | 构建并使用固定内存音频流验证采集至真实模型、字幕及保存 |
| `node scripts/local/evaluate-runtime.mjs` | 使用应用适配层复测固定音频、静音及噪声 |

真实模型测试需要上述模型、运行工具和桌面会话；固定 WAV 不提交仓库，可用 `python3 scripts/local/generate_samples.py` 生成。需要 macOS 本地 Samantha、Daniel、Karen、Tingting 语音。

`test:local` 使用 Chromium 虚拟设备完成权限路径，再注入合成 WAV 对应的内存音频流，绕开虚拟设备读取文件的沙箱限制；正式应用沙箱保持开启，不采集环境声音。此测试不能代替真人设备或签名安装包验收。

本次验证结果见 `outputs/local-runtime-evaluation/接入验证报告.md`；原始文件评测保留在 `outputs/local-evaluation/`。复测脚本会覆盖同名结果，比较不同实验前先备份。

## 已知限制

- 临时 ASR 可能自行补出错误的完整句，例如课程中的 `best option for you`；标点与完整前缀规则无法保证拦住此类错误。问句和跨段衔接改进及残余失败见 `outputs/translation-units/验证报告.md`，未宣称整体提速或准确率达标。

- 中英混合的 `RAG pipeline` 样本仍会误识别为 `WebKeeperLine`，没有硬编码伪修复。已去掉识别阶段固定的软件术语提示，避免干扰普通课程；译文术语规范保留。中英混合 timeout 的原文由正确识别退化为 TIMAT，中文仍正确，此退化保留，尚未解决。不能保证任意术语正确。
- 分段仍是能量与停顿规则，并非完整语义断句；轻声、手机外放、噪声及不同麦克风仍需实测，12 秒强制切段仍可能切开长句。
- 重复拦截是质量保护，不代表恢复了正确原文；刻意多次重复同一短语可能被标记，普通非重复误识别仍可能存在。暂未验证用户所提供课程的前 10 分钟音频。
- 暂停和结束冻结当时页面，不等待尚未返回的翻译，不补录暂停期间声音。
- 尚未验证 20～30 段授权真人样本、1～2 秒体验目标、30～60 分钟持续运行、真实设备拔插和打包权限。
- 当前模型二进制位于开发用 `work/` 目录；制作安装包时需重新规划资源位置，不能只复制界面文件分发。

## 文件存放

`src/` 为界面、音频采集与状态；`public/` 为 AudioWorklet；`electron/` 为模型与桌面接口；`tests/` 为测试；`scripts/local/` 为工具构建、模型准备与评测；`docs/` 为产品文档；`outputs/` 为验证报告；`work/` 为运行工具及临时文件；`models/` 为模型大文件。运行工具、模型、测试音频不提交 Git。
