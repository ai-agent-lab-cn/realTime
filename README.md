# 实译 / Real-time Interpreter

面向英文场景的实时中文字幕工具。本项目目前是 **Electron + Vue 3 + TypeScript 前端 Demo**：使用固定语料模拟字幕增量更新，无后端、不采集麦克风、不发送音频或文字。

## 快速体验

在项目目录 `/Users/zrr/Desktop/实译` 中执行：

```sh
npm install
npm run dev:desktop
```

浏览器预览：`npm run dev`，打开 http://127.0.0.1:5187 。

使用生产资源启动桌面窗口：

```sh
npm run build
npm start
```

要求 Node.js 22.12+（本次使用 22.22.2）。依赖版本由 package-lock.json 固定；已有锁文件时可用 npm ci 安装。Electron 安装会下载对应平台运行包。测试默认使用已安装的 Google Chrome。

## 可以体验的流程

1. 点击“开始翻译”，观看固定技术英文示例的 Partial / Final 字幕，整轮约一分钟。
2. 点击“暂停”冻结字幕；“继续翻译”从下一段示例继续，保留前一条未确认内容。
3. 点击“结束”保留记录，或等待整轮播放完自动结束。
4. 切换双语 / 仅中文、字号和自动滚动；术语开关影响后续生成内容。
5. 复制单条或全部已确认字幕；复制语言随当前显示模式变化。未确认内容不纳入复制。
6. 桌面版结束或演示播放完毕后，自动保存双语 Markdown 到桌面“实译历史记录”；文件注明模拟数据和未确认字幕，支持打开文件夹。
7. 浏览器版结束后点击“下载记录”；下载位置由浏览器决定。
8. 保存失败可重试或下载备份。清空或重新开始只清除页面，不删除历史。关闭窗口前请先结束并确认保存成功。设置保存在此设备。

演示没有音频播放，所有识别、断句和翻译效果都是预设数据。不能据此评价真实识别质量、延迟或服务故障恢复能力。

## 检查命令

| 命令 | 用途 |
|---|---|
| `npm test` | 独立状态规则与可控时钟播放测试 |
| `npm run typecheck` | Vue、TypeScript 与 Electron 类型检查 |
| `npm run test:e2e` | Chrome 操作回归，自动启动或使用本项目预览服务 |
| `npm run build` | 类型检查与前端、Electron 编译 |
| `npm run test:electron` | 构建后运行桌面启动、隔离与剪贴板冒烟 |
| `npm run format` | 格式化源码和配置 |

`test:electron` 需要桌面会话与已下载的 Electron 运行包。当前未制作签名安装包；真实麦克风、服务集成、系统音频及长时间音频验收属于后续工作。
