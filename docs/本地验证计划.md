已确认设备：Apple M3、24GB 内存。用户要求中国大陆环境使用，运行时完全本地；首次下载运行工具和模型允许联网。

1. 已保存 Git 基线 demo-v0.1-baseline，继续保留模拟模式。
2. 项目内独立构建 whisper.cpp 与 llama.cpp，模型放 models/，大文件不提交 Git。
3. 起步候选：Whisper small 多语言、Qwen3-4B-Instruct-2507 Q4_K_M。GGUF 量化来源及 SHA-256 单独记录，不将社区量化版本写成官方发布。

5. 测量模型加载、热启动识别、翻译首输出与完成时间、两个模型同时驻留时的运行表现。音频文件处理时间与真实麦克风端到端延迟分开报告。
6. 在可行时，以进程级网络限制复测只允许本机通信的推理，不改变用户系统 Wi-Fi 设置。
7. 依据测量结果决定是否接入真实模式；未达标时保留 Demo 并给出具体瓶颈和下一步，不声称已完成实时翻译。
