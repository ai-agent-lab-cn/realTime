# Real-time Interpreter / 实时翻译器

MVP 产品设计文档 · V0.1 · 2026-10-08

本文依据原对话最终确认方案整理，作为 Demo 与 MVP 的产品范围基准。文中的功能与指标为设计要求，不代表已经实现或通过验收。

## 一、产品概述与一句话定义

**Real-time Interpreter 是一个面向全英文环境的低延迟实时语音翻译器，将英文或中英混合语音持续转化为易读的中文字幕，并提供原文对照。**

核心价值：把“正在听到的英文”快速、稳定地变成“正在读的中文”，尽可能少打断用户当前行为。

- 输入：英文语音或中英混合语音，V0.1 以麦克风输入为主。
- 输出：原文 + 中文实时字幕，默认双语展示；混合语音的原文保留实际识别语言。
- 定位：通用实时语音翻译工具，不引入会议产品定位。

## 二、产品目标与设计原则

体验优先级：**实时性 > 阅读体验 > 翻译完整度 > 扩展功能**。

| 原则 | 设计要求 |
|---|---|
| 实时优先 | 讲话过程中即输出有效内容，不等待整段讲话结束。 |
| 阅读优先 | 中文为主要阅读内容，英文为辅助对照；字幕按语义分块，不采用聊天气泡结构。 |
| 稳定优先 | Partial 在当前块内更新，减少跳动；Final 固定后不反复重写。 |
| 简单优先 | 打开即可开始，基础设置少而明确，不要求用户先完成复杂配置。 |
| 核心链路优先 | 以“是否帮助用户更快、更稳定地理解当前英文”判断功能是否进入第一版。 |

## 三、目标使用场景

| 场景 | 用户需求 | V0.1 边界 |
|---|---|---|
| 英文交流 | 面对面沟通、英文面试、日常讨论时辅助理解 | 通过麦克风收音，不区分说话人。 |
| 英文课程与演讲 | 边听课程、公开课、Webinar 或技术演讲，边看中文 | 连续展示字幕，不生成课程总结。 |
| 英文视频与音频 | 理解英文直播、Podcast、录播内容 | 仅覆盖可经当前音频输入获取的声音，不承诺直接捕获系统音频，不集成具体平台。 |
| 技术英文内容 | 理解 RAG、Agent、Embedding、Kubernetes 等技术表达 | 优先保留或规范常见术语，不做复杂领域知识推理。 |

## 四、第一版核心链路

```text
Audio Input → VAD → Streaming ASR → Segmentation → Translation → Terminology Processing → Subtitle Rendering
音频输入 → 语音活动检测 → 流式语音识别 → 自动断句 → 实时翻译 → 术语处理 → 字幕展示
```

| 环节 | 责任 |
|---|---|
| Audio Input | 用户授权后持续接收麦克风音频，响应开始、暂停、继续和结束。 |
| VAD | 检测语音活动与停顿，减少静音干扰，为断句提供依据。 |
| Streaming ASR | 持续识别英文及中英混合语音，产生临时结果与最终结果。 |
| Segmentation | 综合停顿、标点和语义完整度形成字幕块，避免过碎或过长。 |
| Translation | 以英译中为默认方向；已有中文保留自然表达，不要求用户预选输入语言。 |
| Terminology Processing | 规范常见专业词汇，保留必要英文，保持前后表达一致。 |
| Subtitle Rendering | 将原文和译文配对展示，区分 Partial / Final，并保留当前记录。 |

这是一条持续运行的流式链路。断句过程可以先提供临时片段供翻译，再在语句确认后生成最终字幕。

## 五、V0.1 主要功能

| 功能 | 第一版要求 |
|---|---|
| 开始 / 暂停 / 继续 / 结束 | 开始后监听；暂停停止新的语音处理并保留记录；继续恢复监听；结束停止输入与字幕更新，保留结果供回看。 |
| 实时识别 | 主要优化英文，兼容中英混合语音，无需复杂语言选择。 |
| 英译中 | 语义准确、表达自然；不提供双向同声传译或翻译语音朗读。 |
| 双语字幕 | 默认“英文原文 + 中文”；可切换“仅中文”，中文视觉权重略高。 |
| Partial / Final | Partial 表示仍可能变化，可用浅色及“正在生成”标识；Final 表示原文和译文均已确认，保持稳定。 |
| 自动断句 | 根据停顿、标点和语义形成易读字幕块，不机械地逐词拆分。 |
| 当前记录 | 按顺序保留本次翻译的原文和译文，可带时间标记；支持向上滚动回看，暂停和结束后仍可查看。 |
| 复制 | 支持单条和全部复制，可复制双语内容或中文译文，并反馈复制结果。 |
| 基础字幕设置 | 显示模式：双语 / 仅中文；字号：小 / 标准 / 大；自动滚动：开 / 关。默认双语、标准字号、自动滚动开启。 |
| 轻量术语处理 | 内置常用术语与简单配置，不建设术语管理后台。 |
| 清空 | 作为次级操作清除当前记录，避免与主控制按钮争夺视觉注意力。 |

### 字幕生命周期

```text
监听 → 临时识别 → 临时翻译 → 最终识别 → 最终翻译 → 字幕块完成
```

同一字幕块可经历多次临时更新。原文已确认但译文尚未完成时，整块仍不标记为 Final。

```text
Partial
We need to improve the RAG...
我们需要改进 RAG……

Final
We need to improve the RAG evaluation pipeline.
我们需要改进 RAG 评测流水线。
```

术语示例：RAG 保留英文；Agent 可按上下文表达为“Agent / 智能体”；Embedding 可表达为“Embedding / 向量嵌入”；Pull Request 可使用 PR；Repository 可表达为“Repository / 仓库”。不要求把所有专业词汇强制翻译成中文。

### 记录与交互补充约定

以下为落实原方案的轻量交互约定，不增加功能模块：

- 当前记录在页面内存中展示。按 2026-10-08 确认的补充方案，桌面版点击结束或自然结束后自动保存到桌面“实译历史记录”文件夹，每轮一个 Markdown 文件；空记录不保存。关闭窗口前应先结束并确认保存成功。浏览器预览提供下载。
- 暂停或结束时冻结当前显示；尚未确认的内容保留 Partial 标记，不伪装成 Final，迟到结果不继续改写页面。
- 复制以已确认内容为默认范围；若包含未确认内容，需保留其状态说明。
- 重新开始创建新一轮记录；存在旧内容时提示其保存状态。清空同样提示确认，仅清除页面内容，不删除历史文件。保存进行中阻止清空和重新开始；失败可重试或下载备份。
- 自动滚动关闭后不强制跳到最新位置，方便回看。

### 本地历史文件（已确认补充）

默认位置：`/Users/zrr/Desktop/实译历史记录`。文件按本地开始时间与唯一记录编号命名，避免同一秒的多轮记录互相覆盖。内容包含开始和结束时间、完整双语字幕及确认状态，不受“仅中文”显示设置影响；未确认内容单独标记，Demo 内容注明“模拟数据”。同一轮重试不重复创建文件。

桌面版提供“打开历史文件夹”；浏览器版只提示下载状态，不声称保存到桌面。无需数据库、云同步或独立历史中心。

## 六、页面结构与四种状态

第一版只有一个主页面，无复杂导航或独立历史中心。

```text
┌──────────────────────────────────────────┐
│ Real-time Interpreter        ● Listening │
├──────────────────────────────────────────┤
│ 已完成字幕：原文 + 中文译文               │
│ 已完成字幕：原文 + 中文译文               │
│ 当前字幕：Partial 持续更新                │
├──────────────────────────────────────────┤
│ 双语 / 仅中文   字号   自动滚动            │
│ 暂停   结束              复制全部         │
└──────────────────────────────────────────┘
```

- **顶部状态区**：产品名称、状态文字；可提供简单音频活动反馈。
- **实时字幕区**：上方为稳定字幕，下方为当前生成字幕；支持回看和单条复制。
- **底部控制区**：主要操作、基础字幕设置及次级操作。

| 页面状态 | 含义与展示 | 主要操作 |
|---|---|---|
| Ready（准备开始） | 尚未监听，显示简短使用提示 | 开始翻译 |
| Listening（正在监听） | 持续接收音频并更新字幕；无语音时提示等待语音 | 暂停、结束 |
| Paused（已暂停） | 不接收新的语音内容，字幕冻结并保留 | 继续、结束 |
| Stopped（已结束） | 输入关闭，字幕保留供回看 | 重新开始、复制全部、清空 |

Partial / Final 是字幕块状态，与以上四种页面状态分开管理。

## 七、主要操作流程

1. **开始与实时阅读**：打开应用 → Ready → 点击“开始翻译” → 首次使用请求麦克风权限 → 输入可用后进入 Listening → 检测语音 → 显示临时原文和中文 → 确认为 Final → 保留该块并继续下一句。
2. **暂停与继续**：Listening → 点击“暂停” → Paused → 保留当前字幕 → 点击“继续” → Listening；暂停期间的声音不补录。
3. **结束与回看**：Listening 或 Paused → 点击“结束” → Stopped → 查看当前记录 → 复制单条或全部内容。
4. **重新开始**：Stopped → 点击“重新开始” → 如有记录，提示先复制并确认开启新一轮 → 输入可用后进入 Listening。
5. **调整阅读方式**：切换双语 / 仅中文、字号或自动滚动，立即影响显示，不清除当前记录。

基础异常反馈：麦克风权限被拒绝或设备不可用时，显示原因和重试提示，不显示为正在监听；处理中服务中断时停止新增处理并进入 Paused，保留当前记录，提示恢复后继续。错误提示不另增第五种页面状态。

## 八、第一版明确不做

- **会议产品能力**：会议实时翻译、Meeting Mode、会议工作区、会议名称、参会者与会议 Timeline。
- **说话人能力**：Speaker Diarization，不标注 Speaker A / B，不区分多人身份。
- **Meeting Intelligence**：会议总结、Key Points、Action Items、Decision、Meeting Minutes。
- **账号与协作**：登录、账号体系、云同步、多设备同步、多人协作。
- **记录与文件扩展**：复杂历史中心、文件翻译、视频文件翻译、SRT 等字幕文件导出。
- **平台集成**：Chrome、Zoom、Teams 插件及具体视频平台集成。
- **AI 扩展**：RAG、Agent、知识库、AI 问答与自动总结。字幕中识别或保留“RAG / Agent”术语不等于实现这些能力。
- **其他扩展**：多语言互译、双向同声传译、翻译语音朗读；系统音频输入留待后续版本。

## 九、MVP 验收标准

以下为待验证目标。使用真实音频链路验收；模拟数据 Demo 仅验证界面、状态与操作流程，不能证明延迟、识别或翻译质量达标。

| 验收项 | 通过标准与检查方式 |
|---|---|
| 实时性 | 在约定测试设备、网络与正常语速下，开始讲话后约 1～2 秒出现有效字幕，且不等待整句结束；分别记录首个原文和首个中文的延迟。 |
| 连续性 | 连续讲话时字幕持续更新，不频繁出现无解释的长时间空白，不积累十几秒后才整段输出。 |
| 状态正确 | 开始、暂停、继续、结束均可重复操作；暂停和结束后不再新增字幕，记录仍可回看。 |
| 字幕稳定 | Partial 在当前块内更新，页面无明显抖动；Final 不再反复改变，不重复追加同一句。 |
| 阅读体验 | 原文与译文对应清晰，中文突出；断句不过碎、不过长；三档字号、显示模式和滚动设置有效。 |
| 翻译与术语 | 用日常英文、技术英文、中英混合语音样本检查：主要语义正确、中文自然，常见技术词无明显误译。 |
| 当前记录与复制 | 本轮 Final 字幕完整有序，结束后可回看；单条及全部复制与所选内容一致，不把 Partial 误标为最终结果。 |
| 持续运行 | 连续运行 30～60 分钟，无崩溃、明显卡顿或字幕持续积压。 |
| 基础异常 | 权限拒绝、输入不可用或服务中断时有明确反馈，不虚假显示工作正常，不丢失已展示记录。 |

验收时保留测试环境、音频样本、实际延迟、运行时长和失败案例。原方案未约定的统计口径与质量评分阈值，应在正式测试前确定，不将“约 1～2 秒”描述为所有环境下的保证。

## 十、后续版本方向

后续方向为规划，需依据 V0.1 验证结果决定投入，不作为当前交付承诺。

| 版本 | 方向 | 主要价值 |
|---|---|---|
| V0.2 | Terminology（术语能力增强）、Translation Context（翻译上下文） | 提高专业表达准确性和前后文一致性，在 V0.1 轻量术语能力上扩展。 |
| V0.3 | 音频输入增强、系统音频、字幕体验优化、长时间运行稳定性 | 扩大可用输入场景，强化持续实时翻译体验。 |
| V0.4 | 按验证结果评估多语言、个性化翻译、桌面悬浮字幕、快捷键、历史记录及其他使用场景 | 改善不同环境中的使用便利性，不预先承诺全部实现。 |

Meeting Mode、Speaker Diarization 与 Meeting Intelligence 暂不进入当前产品路线。
