# 第3、4项优化规划：有限翻译上下文与原生流式识别

日期：2026-10-19。状态：**第3项独立文本A/B已执行；应用上下文未接入；第4项ASR首轮已执行并停止不合格候选，应用运行配置未变**。

## 一、目标与顺序

第3项解决分句单独翻译时的代词指代、否定范围、比较和数字承接；第4项验证原生流式 ASR 能否减少首次英文与中文等待。两项独立对照，不同时改翻译上下文、识别引擎、断句阈值。

建议顺序：冻结基线与样本 → 第3项文本对照 → 第3项音频对照并决定是否采用 → 冻结翻译配置 → 第4项识别对照 → 达标后才规划产品接入。

现有计时的一个短样本：音频首次累计1500ms，ASR约630ms，首次英文显示估算2141ms、中文2701ms；质量检查与页面更新为毫秒级。这说明累计与推理值得继续测量，不足以证明所有课程的主要瓶颈。详见 [上一轮报告](../../../outputs/unit-timings/验证报告.md)。

保留英文质量检查前置、ASR/MT独立队列、分句完成通知、最多两个窗口残句衔接、Final不可回改。完全本地运行，不引入会议、云服务、RAG或Agent。

## 二、第3项：有限前文翻译上下文

### 方案选择

| 方案 | 收益与成本 | 决定 |
|---|---|---|
| 继续逐句独立翻译 | 开销最低，指代歧义仍在 | 作为A组基线 |
| 仅提供有限英文前文，输出当前句 | 可补充指代，不用旧译文传播错误；增加提示词与缓存维度 | 推荐B组实验 |
| 长篇双语历史或整段重译 | 上下文与计算持续增长，旧错误可能影响后文 | 本轮不采用 |

### 上下文规则（建议值，执行前冻结）

1. 最多取目标句前 **2个闭合英文分句**，合计最多120个英文词且800个Unicode码点。超过时按整句从最旧处丢弃，不截断句中数字、否定或术语；单句超限则不纳入。
2. 候选来源：当前请求中目标句之前、已通过质量检查的闭合分句；不足时补最近一个更早且已确认的字幕块中的末尾分句。只提供英文，不使用模型生成的中文作参考。
3. 跨字幕前文只接受同一会话、同一术语设置、音频间隔不超过10秒的先前Final。无可用前文立即按原方案翻译，不等待前句确认；10秒为实验设置，不改变当前音频断句阈值。
4. 每个目标分句冻结上下文快照。当前字幕旧修订、当前目标句、后续文本不得成为跨字幕前文；carry合并后按源句顺序构建，避免把同一句重复送入上下文。
5. 当前请求内前文只在该请求使用；只有对应字幕成功确认为Final后才可成为后续字幕的历史。取消、失败、空译文、异常原文不得提交到历史。暂停、结束、新会话、术语变更清空历史；迟到旧结果不能恢复它。
6. 指令明确“参考前文，仅翻译target；不翻译context，不补写缺失内容”。上下文与目标采用结构化字段传入；音频内容中的指令一律当作待翻译数据。分隔字段不能保证模型绝不误输出，仍须回归和人工复核。
7. 闭合句缓存、整段latest缓存、同源Final复用签名，都必须包含**实际上下文快照、目标句、术语设置及提示词版本**。排版空白可归一化；标点、大小写、数字和否定不得模糊合并。缓存仍只在整轮成功后提交，有界且会话内使用。
8. 已完成单元元数据中的source仍是目标英文，不能混入context；旧Final不重翻，不把上下文加入历史导出或普通计时文件。增加的词数、缓存命中、翻译调用次数仅以数值记录在独立实验结果中。

### 样本与采用门槛

先做20组文本：12组上下文目标（代词、否定、比较、数字各3组），8组独立句控制（术语、无关前文、话题变化、超限前文等）。例如：前文“The timeout is fifteen seconds, not fifty.”，目标“This limit applies only to uploads.”，核对限制对象和数字关系，不指定唯一中文措辞。

文本对照固定参考英文，隔离ASR错误；A/B使用同一Qwen、量化、随机种子、术语配置与输出上限，只改变是否提供前文。冷启动、预热和缓存命中分别记录。随后在固定音频与同一ASR上比较完整链路，不能把纯文本推理时间称为讲话至字幕延迟。

以下为**拟定实验门槛，不是已达到结果**：

- 12组目标中至少4组出现经人工确认的语义改善；若基线无可改善错误，不为凑改善数制造错误，记为“收益未证实”，扩大定向样本后再判断。
- 8组控制无新增含义错误；所有样本不新增数字、单位、否定反转或无依据补写，Final/取消/缓存隔离回归通过。
- 同音频首中文延迟中位数增加不超过150ms、P95增加不超过300ms；比较每个样本3次预热后运行的中位数，再跨样本汇总。缓存命中与未命中分层，不用缓存收益掩盖提示词成本。
- 若质量改善但延迟超限，缩到1句前文重测；仍不达标保留现有默认。没有人工复核时只报告工程结果，不启用为正式默认。

## 三、第4项：原生流式 ASR 对照

### 候选与边界

A组：现有 whisper.cpp + Whisper small累计窗口链路。B组：优先验证 **sherpa-onnx + 英文Streaming Zipformer Transducer**，首选官方文档列出的 `sherpa-onnx-streaming-zipformer-en-2023-06-26` 作为可复现候选，不代表它是当前最佳模型。

官方提供在线解码、持续流状态和CPU示例，项目列出macOS arm64支持，适合作为本机实验候选；这是文档可行性，不是本机性能结论。[在线模型文档](https://k2-fsa.github.io/sherpa/onnx/pretrained_models/online-transducer/zipformer-transducer-models.html)、[项目与平台说明](https://github.com/k2-fsa/sherpa-onnx)。

运行库采用Apache-2.0；权重、词表及其来源许可证须单独核验并留存，不将运行库许可证当作所有权重的分发授权。[运行库许可证](https://github.com/k2-fsa/sherpa-onnx/blob/master/LICENSE)。固定版本、URL、SHA-256、包体与依赖后再开始下载实验；中国大陆首次获取可达性单列，后续断网验证。

不直接替换生产默认，不同时运行两个引擎争抢资源。Whisper的stream示例仍是滚动推理示例，不因名称含stream就当作原生有状态流式解码。[whisper.cpp stream说明](https://github.com/ggml-org/whisper.cpp/blob/master/examples/stream/README.md)。

### 两阶段对照

1. **识别独立实验**：按真实时间每100ms送一块16kHz单声道PCM。Whisper组保持现有累计/分段规则；流式组保留在线状态，不重送历史PCM。内部编码chunk和实际时间戳按模型配置记录，100ms输入不代表100ms一定出词。
2. **接翻译的实验分支**：独立实验过门槛后才连接同一质量检查、文本整理、翻译和显示流程。翻译配置固定为第3项作出选择后的版本；两组MT都相同。暂不更改正式桌面入口。

ASR endpoint只表示声学窗口结束，不直接等于双语字幕Final；不能绕过质量检查，也不能遇静音就自动Paused。独立VAD与候选endpoint职责必须明确，避免重复等待。候选若缺少标点，要测同一整理器下的实际断句与翻译等待；不能只比较出词速度，隐藏标点恢复成本。若需新标点模型，作为单独候选说明成本，不在主对照中静默加入。

英文模型对中英混合可能不适用：保留混合样本并单列结果。不得删除失败样本，也不据英文集胜出就全局取代多语言Whisper。若英文有效而混合显著退化，仅可提出英文专用实验模式，另行决定是否做界面。

### 指标与采用门槛

先用20～30段固定音频：日常英文、原课程、技术术语、数字与否定、长句停顿、轻噪声、中英混合。当前已核对正式基准中的16段课程有既往人工确认；其余pending/unclear项仍单列。用户此前暂搁后续人工听校，本轮不发起新听校或冒称新增完成。未确认参考可做延迟和输出观察，不进入正式WER分母；正式采用结论必须等待足够人工确认参考。

每个样本按配对顺序A/B、B/A交替，预热后各3次；冷启动另列；不并行跑本地推理。统计首个非空英文、人工判定首个有效英文、稳定有效片段、末字至识别终态、首中文与双语Final；纯ASR阶段无中文指标则标记未执行。记录WER、关键数字/否定/术语、遗漏/重复、队列、重复翻译次数、CPU与峰值RSS。英文WER不适用于混合集，混合按字符/词及关键语义分开报告。准确率每段参考与方法固定，不把3次重复当成3倍独立语料。

以下为**拟定采用门槛**：

- 相对现有基线，首个有效英文中位数同时降低至少25%且300ms，P95不变差；稳定有效片段也不变慢。没有人工起止标注时仅给采样时间线估算，不声称物理收音端到端达标。
- 人工确认英文集的总体WER不劣于基线超过1个百分点；逐样本报告，技术、数字、否定分组不被平均值掩盖；不新增严重关键语义错误。样本不足则标“证据不足”，不是通过。
- 完整链路首中文中位数最多增加150ms、P95最多增加300ms；不可仅提前出现一两个无意义词而完整可理解内容更晚。
- 实时处理无持续积压；30分钟持续运行后无崩溃、无重复追加、无Final回改，暂停/继续释放与会话隔离通过；静音不触发无提示自动暂停。
- 如只达到识别阶段指标，报告“ASR实验通过，产品接入待验”；如准确率或完整链路不达标，保留Whisper默认，不以首词更快为由强行切换。
